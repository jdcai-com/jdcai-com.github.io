Zookeeper安装

1. 安装Java环境

sudo yum install -y java-1.8.0-openjdk-devel

2. 创建并进入安装目录

mkdir -p /home/admintalu/u01/tool cd /home/admintalu/u01/tool

3. 下载并解压ZooKeeper

wget https://archive.apache.org/dist/zookeeper/zookeeper-3.4.12/zookeeper-3.4.12.tar.gz tar -zxvf zookeeper-3.4.12.tar.gz cd zookeeper-3.4.12

4. 配置ZooKeeper

mkdir -p data cp conf/zoo_sample.cfg conf/zoo.cfg sed -i "s|dataDir=/tmp/zookeeper|dataDir=/home/admintalu/u01/tool/zookeeper-3.4.12/data|g" conf/zoo.cfg

5. 设置环境变量

echo '# ZooKeeper环境变量' >> ~/.bashrc echo 'export ZOOKEEPER_HOME=/home/admintalu/u01/tool/zookeeper-3.4.12' >> ~/.bashrc echo 'export PATH=$PATH:$ZOOKEEPER_HOME/bin' >> ~/.bashrc source ~/.bashrc

6. 配置系统服务（开机启动）

sudo tee /etc/systemd/system/zookeeper.service << 'EOF' [Unit] Description=Zookeeper Service After=network.target

[Service] Type=forking User=admintalu Group=admintalu ExecStart=/home/admintalu/u01/tool/zookeeper-3.4.12/bin/zkServer.sh start ExecStop=/home/admintalu/u01/tool/zookeeper-3.4.12/bin/zkServer.sh stop ExecReload=/home/admintalu/u01/tool/zookeeper-3.4.12/bin/zkServer.sh restart Restart=on-failure

[Install] WantedBy=multi-user.target EOF

7. 启动并设置开机启动

sudo systemctl daemon-reload sudo systemctl enable zookeeper sudo systemctl start zookeeper

8. 验证安装

echo "ZOOKEEPER_HOME: $ZOOKEEPER_HOME" zkServer.sh status zkServer.sh version
