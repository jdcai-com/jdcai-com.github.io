JDC 微服务项目启动方案

根据您提供的 history 命令记录，我为您整理了一套 JDC 微服务项目启动方案，包括环境检查、服务启动顺序、常见问题排查等，帮助您更高效、稳定地启动整套系统。 ✅ 一、环境检查 在启动 JDC 服务之前，请确保以下中间件服务已正常启动：

  1. MySQL mysql -u root -p

    若无法登录，尝试重启

    service mysqld restart
  2. Redis cd ~/web/tool/redis-4.0.11/src/ ./redis-server ../redis.conf
  3. RabbitMQ rabbitmq-server -detached rabbitmqctl status
  4. RocketMQ cd ~/web/tool/rocketmq-all-4.3.0-bin-release/ nohup sh bin/mqnamesrv & nohup sh bin/mqbroker -n localhost:9876 -c broker.properties &
  5. Zookeeper cd ~/web/tool/zookeeper-3.4.12/bin/ ./zkServer.sh start
  6. Nginx（前端代理） nginx nginx -s reload 🚀 二、JDC 微服务启动顺序 建议按以下顺序启动，以避免服务间依赖问题：
  7. Eureka（注册中心） cd ~/web/jdc/ nohup java -jar jdc-eureka.jar >/dev/null 2>&1 &
  8. Discovery（服务发现） nohup java -jar jdc-discovery.jar >/dev/null 2>&1 &
  9. 各个微服务模块（按需） nohup java -jar jdc-provider-uac.jar >/dev/null 2>&1 & nohup java -jar jdc-provider-mdc.jar >/dev/null 2>&1 & nohup java -jar jdc-provider-omc.jar >/dev/null 2>&1 & nohup java -jar jdc-provider-opc.jar >/dev/null 2>&1 & nohup java -jar jdc-provider-tpc.jar >/dev/null 2>&1 &
  10. Gateway（网关） nohup java -jar jdc-gateway.jar >/dev/null 2>&1 & 🔍 三、检查服务状态 ps -ef | grep jdc 确认各服务是否启动成功，例如： root 12345 1 0 10:00 pts/0 00:00:30 java -jar jdc-eureka.jar root 12346 1 0 10:01 pts/0 00:00:29 java -jar jdc-gateway.jar ... 🧩 四、前端服务（Node.js） cd ~/web/node-server/ npm run prd ⚠️ 五、常见问题与排查
  11. 服务启动失败或闪退 查看日志：cd ~/logs/ ll tail -f jdc-provider-uac.log 检查端口占用：netstat -tunlp | grep 8080
  12. 服务注册不上 Eureka 检查 application.yml 中 eureka.client.service-url.defaultZone 配置是否正确。
  13. 中文乱码（如您之前遇到的问题） 确保启动脚本或 JVM 参数中包含：java -Dfile.encoding=UTF-8 -jar jdc-provider-uac.jar 📌 六、推荐脚本（一键启动） 您可以将上述命令整合为一个 start-jdc.sh 脚本：

    !/bin/bash

    启动基础服务

    echo "Starting MySQL..." service mysqld restart echo "Starting Redis..." cd ~/web/tool/redis-4.0.11/src/ ./redis-server ../redis.conf & echo "Starting RabbitMQ..." rabbitmq-server -detached echo "Starting Zookeeper..." cd ~/web/tool/zookeeper-3.4.12/bin/ ./zkServer.sh start

    启动 JDC 微服务

    cd ~/web/jdc/ nohup java -jar jdc-eureka.jar >/dev/null 2>&1 & nohup java -jar jdc-discovery.jar >/dev/null 2>&1 & nohup java -jar jdc-provider-uac.jar >/dev/null 2>&1 & nohup java -jar jdc-provider-mdc.jar >/dev/null 2>&1 & nohup java -jar jdc-gateway.jar >/dev/null 2>&1 & echo "All services started." 然后执行： chmod +x start-jdc.sh ./start-jdc.sh 如需我帮您生成更精细的启动脚本（如带日志轮转、自动重试机制等），或者协助排查某个服务启动问题，请告诉我具体报错或日志内容。
